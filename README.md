# 🇹🇳 Découvre Tunisie

## Présentation du projet

**Découvre Tunisie** est une application mobile développée avec Flutter et Dart, qui permet aux utilisateurs de découvrir les différentes destinations touristiques en Tunisie.

L'application propose une expérience simple et intuitive pour explorer les lieux touristiques, consulter leurs informations et organiser sa découverte du pays.

## Fonctionnalités principales

- Découverte des destinations touristiques en Tunisie.
- Affichage des images et des détails de chaque lieu.
- Classification des destinations par catégorie : Histoire, Plage, Désert, Nature et Médina.
- Filtrage des destinations par région et par catégorie.
- Recherche des lieux touristiques par nom.
- Gestion des lieux favoris.

## Technologies utilisées

- **Flutter** : développement de l'interface mobile.
- **Dart** : langage de programmation.
- **Visual Studio Code** : environnement de développement.
- **Git & GitHub** : gestion et hébergement du code source.

## Installation et lancement

1. Cloner le dépôt GitHub :

```bash
git clone URL_DU_DEPOT
```

2. Accéder au dossier du projet :

```bash
cd decouvre_tunisie
```

3. Installer les dépendances :

```bash
flutter pub get
```

4. Lancer l'application :

```bash
flutter run
```

## Objectif du projet

L'objectif de cette application est de valoriser le tourisme tunisien en facilitant la découverte des richesses naturelles, historiques et culturelles du pays.
